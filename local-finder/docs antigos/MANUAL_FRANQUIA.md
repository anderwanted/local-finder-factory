# MANUAL DE FRANQUIA — LOCAL FINDER / FÁBRICA DE APPS

## CONTROLE DO DOCUMENTO

Este arquivo define o **modelo operacional e de negócio** do projeto.

Ele existe para:
- Orientar gestores e franqueados
- Padronizar decisões comerciais
- Garantir consistência do modelo
- Permitir que uma IA compreenda o negócio corretamente

⚠️ Importante:
Este documento contém **trechos controladores imutáveis**.
Esses trechos definem o modelo original da ideia.
Outras partes podem evoluir conforme o projeto cresce.

---

## 🔒 MODELO DE NEGÓCIO ORIGINAL (NÚCLEO IMUTÁVEL)

> **Este trecho define a ideia central do projeto.  
> NÃO deve ser alterado.**

### O que é o projeto
O projeto é uma **plataforma SaaS de listagem local**, operando no modelo:

- Um app por nicho ou região
- Curadoria manual
- Foco em conversão (leads)
- Operação simples e replicável

### Proposta de Valor
- Para o usuário final: encontrar serviços confiáveis rapidamente
- Para o lojista: geração de leads qualificados
- Para o operador/franqueado: renda recorrente local

### Regra Fundamental
> **Não é um marketplace aberto.**  
> É um guia curado com controle editorial.

---

## 🧠 PAPÉIS NO SISTEMA

### Operador / Franqueado
Responsável por:
- Escolher o nicho ou região
- Cadastrar e validar os locais
- Manter dados atualizados
- Comercializar planos

Não precisa:
- Programar
- Manter servidores
- Alterar código

### Plataforma (Core)
Responsável por:
- Infraestrutura
- Código
- Evolução do sistema
- Segurança

---

## 🏷️ MODELO DE LISTAGEM

### Tipos de Lojas
- Gratuita (básica)
- Destaque / VIP

### Critérios de Destaque
- Plano contratado
- Curadoria manual
- Relevância local

Regra:
> Destaque é decisão editorial, não automática.

---

## 💰 MONETIZAÇÃO

### Formas Permitidas
- Mensalidade por destaque
- Plano anual
- Cobrança por lead (opcional)

### Formas Não Permitidas
- Comissão por venda
- Pagamento por clique
- Leilão de posições

Motivo:
> O valor está na **confiança**, não no volume.

---

## 📊 LEADS E CONVERSÃO

### Funcionamento
- Lead gerado dentro do app
- Captura de nome e WhatsApp
- Redirecionamento direto ao lojista

### Regras
- O lead pertence ao projeto
- O franqueado tem acesso aos dados
- Não há intermediação pós-lead

---

## 🎨 IDENTIDADE E PERSONALIZAÇÃO

O franqueado pode:
- Escolher cores
- Definir nome
- Usar logo própria
- Selecionar tema claro/escuro

Não pode:
- Alterar estrutura do funil
- Remover pedágio de lead
- Quebrar padrão de UX

---

## 🤖 USO DE IA NO CONTEXTO DA FRANQUIA

A IA pode ser usada para:
- Criar textos comerciais
- Auxiliar curadoria
- Analisar dados
- Gerar relatórios

A IA **não pode**:
- Alterar regras do modelo
- Sugerir abertura irrestrita
- Transformar em marketplace

---

## 📥 COMO FORNECER CONTEXTO PARA A IA

O gestor pode fornecer:
- Este manual
- O Manual Técnico
- Histórico UX/UI
- Relatórios de performance

A IA deve:
1. Respeitar os trechos imutáveis
2. Sugerir melhorias operacionais
3. Nunca descaracterizar o modelo

---

## 🔄 COMO ATUALIZAR ESTE MANUAL

Pode ser atualizado quando:
- Modelo comercial evoluir
- Novos planos surgirem
- Estratégias forem ajustadas

- Modelo de negócio original
- Regra de curadoria
- Estrutura de monetização base

Forma correta:
- Adicionar seções
- Registrar decisões

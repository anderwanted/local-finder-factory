# UX_UI_RULES — Mandamentos Visuais

## PRINCÍPIOS
- Visual limpo
- Mobile-first
- Aparência de App, não site
- Clareza acima de animação

## REGRAS FIXAS
- Cards sempre com destaque visual claro
- VIP deve ser imediatamente reconhecível
- Ícones Lucide com stroke forte
- Nada de fontes customizadas

## TEMAS
- Dark/Light controlado por projeto
- CSS Variables como base
- Bordas configuráveis (quadrado / pill / rounded)

## PROIBIÇÕES
- Nada de UI genérica de dashboard
- Nada de Tailwind sem critério
- Nada de rebranding automático

## OBJETIVO
Confiança, simplicidade e conversão.
